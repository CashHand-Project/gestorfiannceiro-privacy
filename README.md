# Política de Privacidade — Gestor Financeiro

**Última atualização:** 01 de junho de 2026

## 1. Introdução

O **Gestor Financeiro** é um aplicativo de controle de finanças pessoais desenvolvido por **Makdoney Brito**. Esta política descreve como tratamos suas informações.

## 2. Dados que o aplicativo coleta

### 2.1 Dados inseridos pelo usuário
O aplicativo armazena **localmente no seu dispositivo** as informações que você mesmo cadastra:
- Transações financeiras (entradas e saídas)
- Categorias e descrições das transações
- Preferências de tema (claro/escuro)

**Esses dados nunca são enviados para servidores externos.** Ficam armazenados exclusivamente no seu aparelho e são apagados se você desinstalar o aplicativo ou limpar os dados do app.

### 2.2 Dados coletados pelo Google AdMob
O aplicativo exibe anúncios fornecidos pelo **Google AdMob**. O AdMob pode coletar:
- Identificador de publicidade do dispositivo (Ad ID)
- Dados de interação com anúncios
- Informações de diagnóstico e desempenho

Esses dados são tratados pelo Google conforme a [Política de Privacidade do Google](https://policies.google.com/privacy).

## 3. Como usamos as informações

| Dado | Finalidade |
|------|-----------|
| Transações financeiras | Exibir resumos, histórico e análises dentro do app |
| Preferências | Salvar configuração de tema escolhida pelo usuário |
| Dados do AdMob | Exibição de anúncios relevantes (gerenciado pelo Google) |

## 4. Compartilhamento de dados

**Não compartilhamos, vendemos nem transferimos seus dados pessoais a terceiros.**

O único terceiro com acesso a dados é o **Google AdMob**, exclusivamente para fins publicitários, conforme descrito na seção 2.2.

## 5. Armazenamento e segurança

- Todos os seus dados financeiros são armazenados localmente no dispositivo usando o mecanismo de armazenamento seguro do Android.
- Não mantemos servidores, bancos de dados em nuvem nem backups externos dos seus dados.
- A segurança dos dados está sujeita às proteções do próprio sistema operacional Android.

## 6. Crianças

Este aplicativo não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados de crianças.

## 7. Seus direitos

Como seus dados ficam apenas no seu dispositivo, você tem controle total:
- **Apagar:** desinstale o app ou use "Limpar dados" nas configurações do Android.
- **Opt-out de anúncios personalizados:** acesse *Configurações do Android → Google → Anúncios → Desativar personalização de anúncios*.

## 8. Alterações nesta política

Eventuais atualizações serão publicadas nesta página com a data de revisão atualizada.
